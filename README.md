# Fluttershy.EXE — Clean Build

Полностью новая реализация игры без старого приложения, серверного кода и старой игровой архитектуры.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Управление

- `A / D` или `← / →` — движение
- `W / ↑ / SPACE` — прыжок
- `E / ENTER` — открыть дверь
- `P / ESC` — пауза

## Игра

Четыре самостоятельные главы: сад, туман, разрыв и финальная зона. Собирай фрагменты памяти, следи за уровнем страха и доберись до двери. При высоком страхе появляется преследователь.

Прогресс сохраняется в `localStorage`. Смерть сбрасывает только прогресс текущей главы, поэтому повторное прохождение остаётся честным и предсказуемым.

## Архитектура

- `src/main.js` — точка входа и конфигурация Phaser
- `src/game/BootScene.js` — загрузка ресурсов
- `src/game/MenuScene.js` — меню и сохранение
- `src/game/GameScene.js` — игровой цикл
- `src/game/Player.js` — игрок и сборка уровней
- `src/game/LevelData.js` — данные четырёх глав
- `src/game/GameState.js` — состояние прохождения
- `src/game/Storage.js` — безопасное сохранение
- `src/game/FinaleScene.js` — три варианта финала

Система построена вокруг Phaser 3 + Vite и не требует сервера, базы данных или React.
