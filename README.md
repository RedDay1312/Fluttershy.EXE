# FLUTTERSHY.EXE // REBORN

Полный самостоятельный rebuild игры. Старый игровой код не используется: приложение, управление, мир, хоррор-система, HUD, сохранение и финалы написаны заново.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Для Windows можно запустить `start-game.bat`.

## Управление

- A / D или стрелки — движение
- Space — прыжок
- Escape — пауза

## Структура

`src/main.js` запускает Phaser. `BootScene` загружает единственный внешний ресурсный слой — сохранённые спрайты. `World`, `LevelBuilder` и `LevelData` создают уровни. `Player` отвечает за физику персонажа. `HorrorDirector` управляет нарастающим страхом и событиями. `HUD` рисует интерфейс. `AudioEngine` генерирует базовые звуки без внешних аудиофайлов. `Storage` отвечает за локальное сохранение.

## Ресурсы

Папка `public/sprites` сохранена и используется новой игрой. Старые игровые сцены и старые программные зависимости не являются частью новой архитектуры.
